# تشغيل اللعبة (بدون قاعدة بيانات)

اللعبة تخزّن كل شي في ذاكرة السيرفر، ما بدها DATABASE_URL ولا SQL.
مهم: لازم تشتغل على سيرفر واحد ثابت (مش Vercel serverless).

## الطريقة 1: على جهازك (الأسهل)
1. ثبّت Node.js (نسخة LTS) من nodejs.org
2. افتح terminal داخل مجلد المشروع:
       npm install -g pnpm
       pnpm install
       pnpm build
       pnpm start
3. افتح http://localhost:3000/host  (صفحة المضيف)
4. اللاعبين على نفس الواي فاي يدخلوا على  http://عنوان-جهازك:3000
   (عنوان الجهاز: على ويندوز اكتب ipconfig وخذ IPv4)

## الطريقة 2: أونلاين على Render (مجاني)
1. ارفع المجلد على GitHub.
2. في render.com: New + > Web Service > اختار الـ repository.
   الملف render.yaml فيه الإعدادات جاهزة.
3. بعد النشر بياخد رابط: your-app.onrender.com
   - المضيف: /host
   - اللاعبين: الرابط الرئيسي

ملاحظة: الخطة المجانية بتنام بعد فترة خمول، فافتح الرابط قبل اللعبة بدقيقة.
